# 06 时间口径

六、统一时间：区分发生时间、购买批次和快照状态

至少区分：

1. 下单时间；
2. 支付时间；
3. 核销时间；
4. 退款完成时间；
5. 数据导出时间。

例如：
“9月1—9日购买的订单，截至10日导出时的退款情况”
不等于
“9月1—9日发生的所有退款”。

如果用户要求“截至9日”的状态，但文件只有10日的最新状态：
- 有完整事件记录时，可以按事件时间重建；
- 缺少撤销、退款或状态变更历史时，不能声称精确重建；
- 明确写“使用导出时状态，无法完全还原9日历史状态”。

完整自然日使用：
开始时间 <= 业务时间 < 结束日期的次日00:00。

未结束的一天不能直接与完整一天比较。
