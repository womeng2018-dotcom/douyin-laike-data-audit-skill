# 08 核心算法四至六

十、核心算法四：比较先检查可比性，再讨论差异

比较前逐项检查：

- 是否相同星期结构；
- 是否完整自然日；
- 商品ID、价格和优惠是否变化；
- 门店、营业、预约承接是否变化；
- 渠道、人群、新老客结构是否变化；
- 投放预算、素材和计划状态是否变化；
- 归因窗口是否一致；
- 退款、核销观察年龄是否一致。

推荐顺序：

总体变化
→ 按商品/渠道/门店等分层
→ 检查各层内部变化
→ 检查各层占比变化

整体结果改变可能来自：
A. 各组内部表现改变；
B. 好组或差组的占比改变；
C. 两者同时发生。

如果要比较固定结构下的比率：
选定一套公开说明的共同权重w，
计算 标准化比率 = Σ(w × 各组比率)。
各组必须有可用分母，权重总和为1。
不能默默删除缺失组再重新加权。

分层或标准化有助于比较，但不自动消除全部混杂。


十一、核心算法五：样本量与统计不确定性

首先区分：
“准确描述本次已记录数据”
与
“推断未来、其他用户或因果效果”。

若数据是该范围内完整记录，
本次总额不需要靠置信区间证明其存在。
不确定性主要来自数据质量、未成熟结果和外推条件。

样本量必须按研究问题确定。

研究订单金额，可能以订单为单位。
研究用户转化，可能以用户为单位。
研究投放对每日销售的影响，独立单位可能是日期或实验组。

2,000笔订单不等于2,000次独立投放实验。

同一用户多次购买、同一门店集中成交、
同一计划算法分配流量，都可能形成相关性。

禁止使用固定门槛：
- 1000曝光一定够；
- 30个样本就可靠；
- 7天一定可以下结论。

样本计划应取决于：
基准水平、希望识别的最小业务差异、
误判容忍度、统计功效和实验单位。

只有符合独立二项试验假设时，才使用普通比例区间。

可使用Wilson比例区间：
p = k/n
z = 1.96，对应通常使用的95%区间

中心 =
[p + z²/(2n)] / [1 + z²/n]

半宽 =
z × sqrt[p(1－p)/n + z²/(4n²)] / [1 + z²/n]

区间 = 中心 ± 半宽

限制：
- k必须是明确的成功次数，n是对应试验次数；
- n必须大于0；
- 如果一人多次曝光、同群流量高度相关，
  不能默认每次曝光都是独立样本；
- 不将该公式用于ROI或客单价；
- 不用两个区间是否重叠，代替正式的差异比较。

置信区间用于表达抽样不确定性，
不能弥补错误归因、数据缺失或系统性偏差。

没有显著差异，不等于两者相同。
p值不是“原假设为真的概率”。
统计显著不等于改善足够大，也不等于赚钱。

大量商品同时比较时，要考虑多重比较。
不熟悉适当方法时，将结果标注为探索性筛查，
不能宣布挑出的第一名已被统计证明最好。


十二、核心算法六：因果判断与实验

证据类型分开标注：

1. 数据事实：
   本次记录显示什么。

2. 观察性比较：
   不同组或不同时段存在什么差异。

3. 业务假设：
   哪些机制可能解释差异。

4. 因果证据：
   是否有可信实验设计或明确条件支持。

“调整后上涨”只能先算时间关联。
“平台归因成交”不等于“广告新增成交”。

即使消费400元、平台归因成交4万元，
也不能自动断言“不投广告就会少卖4万元”。

实验开始前必须记录：
- 假设；
- 随机分配或比较单位；
- A/B差异；
- 主指标；
- 业务上值得关注的最小改善；
- 风险指标；
- 样本与观察窗口；
- 预算上限；
- 停止规则；
- 退款核销后续复查节点。

控制城市、商品和预算，不等于完成随机实验。
不能可靠随机分流时，标记为对照观察，
明确人群选择、时间、平台分流等限制。

不使用普通固定样本检验每天反复窥看，
看到显著就提前停止。
如需连续监测，使用事先约定且适用的序贯方法。

达到预算上限可以停止测试，
但“停止花钱”不等于“已经证明素材无效”。
